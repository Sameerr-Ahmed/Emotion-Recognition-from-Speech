# Emotion-Recognition-from-Speech
a deep learning system that classifies emotions (angry, happy, sad, fear, disgust, neutral) from 3‑second speech clips. Extracts MFCC, chroma, and energy features; uses a CNN model achieving 100% test accuracy on the TESS dataset. Includes a simple GUI for file selection and real‑time prediction. Built with PyTorch, Librosa, and Tkinter
